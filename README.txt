jol.kg local test server

Requirements: Python 3.8+

Start:
- Windows: double-click start-server.bat
- macOS/Linux: ./start-server.sh
- Any system: python3 server.py

Open:
- Customer site: http://127.0.0.1:8000/
- Admin panel: http://127.0.0.1:8000/admin.html

Demo admin login:
Email/username: admin@jol.kg
Password: jol-admin

Stop with Ctrl+C in the server window.
